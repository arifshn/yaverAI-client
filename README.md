# Yaver - Frontend

> AI destekli asistan uygulamasının React TypeScript frontend projesi

## 📋 Proje Hakkında

Yaver, kullanıcıların günlük işlerini kolaylaştırmak için geliştirilmiş yapay zeka destekli bir asistan uygulamasının frontend katmanıdır. ChatGPT API'si ile entegre çalışarak kullanıcılara akıllı yanıtlar sunar.

## 🚀 Özellikler

- ✨ Modern ve kullanıcı dostu arayüz
- 🤖 ChatGPT entegrasyonu ile AI destekli sohbet
- 💬 Gerçek zamanlı mesajlaşma
- 🎨 Responsive tasarım (mobil uyumlu)
- ⚡ Hızlı ve performanslı
- 🔒 Güvenli API iletişimi
- 📱 Progressive Web App (PWA) desteği

## 🛠️ Teknolojiler

- **Framework:** React 18+ with TypeScript
- **State Management:** Redux Toolkit / Context API
- **Styling:** Tailwind CSS / Material-UI / Styled Components
- **HTTP Client:** Axios
- **Routing:** React Router v6
- **Build Tool:** Vite / Create React App
- **AI Integration:** OpenAI ChatGPT API
- **Backend API:** C# (.NET) REST API
- **Database:** SQL Server (backend tarafında)

## 📦 Kurulum

### Gereksinimler

- Node.js (v18 veya üzeri)
- npm veya yarn veya pnpm
- Git

## 🎯 Kullanım

1. Backend API'nin çalıştığından emin olun (varsayılan: `https://localhost:7001`)
2. Frontend'i başlatın: `npm run dev`
3. Tarayıcıda açılan sayfada hesap oluşturun veya giriş yapın
4. ChatGPT destekli Yaver asistanı ile sohbet etmeye başlayın!
